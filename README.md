# Пошук слів · Word Search

Безкоштовна навчальна гра для уроків: вчитель вставляє власний список слів, гра будується автоматично, а потім ним можна поділитися з учнями одним посиланням.

Це один HTML-файл без сторонніх бібліотек і без сервера.

**Демо:** https://codenamexxv.github.io/wordsearch/

## Можливості

- **Власний список слів.** Слова можна вставляти по одному в рядок або через кому чи крапку з комою (до 30 слів).
- **Три рівні складності.**
  - Легко: компактне поле, слова йдуть зліва направо та зверху вниз, зайві літери не збігаються з першими літерами слів.
  - Середньо: додаються діагоналі.
  - Складно: більше поле, слова розташовані у всіх 8 напрямках, зокрема навспак.
- **Розмір поля** залежить від складності та кількості літер у словах. За потреби його можна задати вручну: 10×10, 12×12, 15×15 або 18×18.
- **Поділитися грою.** Список слів і налаштування зашиваються в посилання, тож учні відкривають його й одразу грають. Усі отримують однакове поле. Також є код гри (5 цифр), який можна вставити на головній сторінці.
- **Зручне керування.** Слово виділяється мишею чи пальцем, одним рухом по літерах. Знайдені слова підсвічуються й викреслюються, є таймер.
- Працює на комп’ютері, планшеті та телефоні.
- Українська мова, але підтримуються й інші мови: у сітці використовуються лише літери та цифри, а апострофи й дефіси ігноруються.

## Як користуватися

1. Вставте слова у поле на головній сторінці.
2. Оберіть складність.
3. Натисніть **«Створити гру»**, щоб зіграти самому, або **«Поділитися грою»**, щоб одразу отримати посилання для учнів.

## Запуск на GitHub Pages

1. Збережіть файл гри як `index.html` у корені репозиторію.
2. У репозиторії відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. За хвилину гра буде доступна за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Посилання для учнів формується з адреси сторінки автоматично, тому окремого налаштування не потрібно.

## Короткий код із 5 цифр

Щоб учитель отримував простий код (наприклад, `48213`), потрібне невелике сховище. Гра використовує Firebase Realtime Database через звичайні запити, без SDK.

1. Створіть проєкт у Firebase і додайте **Realtime Database**.
2. У розділі **Rules** вставте:

```json
{
  "rules": {
    "games": {
      "$id": {
        ".read": true,
        ".write": "!data.exists() && $id.matches(/^[0-9]{5}$/)",
        ".validate": "newData.hasChild('c') && newData.child('c').isString() && newData.child('c').val().length < 3000"
      }
    }
  }
}
```

3. У файлі `index.html` знайдіть рядок `const DB_URL='';` і вставте адресу бази, наприклад `https://ваш-проєкт-default-rtdb.europe-west1.firebasedatabase.app`.

Якщо `DB_URL` порожній, гра працює без сервера, але код і посилання вийдуть довгими.

## Технічні деталі

- Один файл `index.html`: HTML, CSS та JavaScript без залежностей.
- Єдиний зовнішній ресурс — шрифт Roboto із Google Fonts. Без інтернету використовується Arial.
- Налаштування гри (слова, складність, розмір, число для генератора поля) кодуються в Base64 і зберігаються в хеші посилання (`#...`). Без підключеної бази даних ніякі дані не надсилаються на сервер.
- Генератор поля використовує seed, тому гра за одним посиланням завжди виглядає однаково.
